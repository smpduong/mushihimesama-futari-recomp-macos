# Security reporting

Do not attach game executables, game or DLC data, saves, replay files, private
keys, access tokens, or personal receipts to an issue. Do not include account
diagnostics or unredacted local paths.

For a security report, provide a short description, affected source file or
version, and a minimal reproduction using synthetic data. If a log is needed,
share only the smallest relevant excerpt after removing names, tokens, local
paths, and game-derived content. Do not post credentials or private user data
in a public issue.
