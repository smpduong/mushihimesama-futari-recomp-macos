# Contributing

Keep changes within the handwritten host tools, packaging/replay helpers,
documentation, and focused tests represented in this repository. Do not add
game files, generated guest code, compiled modules, shaders, saves, replays,
personal receipts, or machine-specific paths.

Before opening a change, run the two checks in the README. Include a concise
reproduction using synthetic inputs where possible, and describe which
behavior the check covers. Do not present a host-tool check as proof of
gameplay or compatibility across all modes.

The root `LICENSE` covers original project-authored source and documentation.
Third-party material must retain its notices; see `THIRD_PARTY_NOTICES.md`.
